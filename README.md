# MiraVolt Games

Україномовний каталог безкоштовних та free-to-play ігор для ПК.

[Відкрити сайт](https://vizonok.github.io/miravolt-games/)

- website.zip — готовий статичний сайт.
- source.zip — повний вихідний код, генератор сторінок і тести.
- .github/workflows/pages.yml — автоматична публікація GitHub Pages.

Для розробки розпакуйте source.zip, відкрийте папку miravolt-games і виконайте npm run build, потім npm run dev. Потрібен Node.js 20.11 або новіший; зовнішніх залежностей немає. Команди npm test і npm run check перевіряють логіку каталогу та зібрані сторінки.

Для оновлення зберіть сайт із SITE_URL=https://vizonok.github.io/miravolt-games/, запакуйте вміст dist у website.zip і замініть цей архів у репозиторії. GitHub Actions автоматично опублікує зміни.

Каталог містить 12 ігор, пошук, жанрові фільтри, сортування, локальну добірку й окремі сторінки. Дані перевіряються вручну. Ігри завантажуються з офіційних джерел, а не з цього сайту.

Назви та зображення ігор належать відповідним правовласникам. Перелік джерел доступний на сторінці «Про сервіс».
