# Промпт до проєкту MiraVolt Games

Нижче наведено стислий технічний зміст запиту та уточнень, використаних у роботі з ChatGPT/Codex. Це зведення вимог, а не дослівний експорт особистого листування.

> Для дисципліни «Управління IT проєктами» підготуй вебверсію каталогу безкоштовних і умовнобезкоштовних ігор для ПК та сформулюй ціль цього проєкту методом SMART за лекцією 5. Назва сайту — MiraVolt Games. Орієнтир структури інтерфейсу — Epic Games Store. Використай фірмові кольори MiraVolt і наявний оригінальний логотип. Інтерфейс українською, без коментарів у коді. Реалізуй каталог, пошук, фільтри, сторінки ігор, збереження добірки й посилання на офіційні джерела. Перевір роботу на комп’ютері та телефоні й підготуй публікацію на безкоштовному GitHub Pages.

Уточнення щодо дизайну: після перегляду попередніх напрямів обрано темний магазин із великим банером, перемиканням рекомендованих ігор, портретними обкладинками, фіолетовими кнопками та лаймовими акцентами.

У SMART визначено обсяг першої версії, вимірювані критерії приймання, ресурсні обмеження, плановий строк і протокол перевірки з користувачами. Фактичне тестування з п’ятьма людьми ще потрібно провести; його результати не вигадувалися.
